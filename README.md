# Café Souvenir — Website

A restaurant website for **Café Souvenir**, 1261 Bernard Ave, Outremont, Montréal.

## File structure

```
cafe-souvenir/
├── index.html          ← main website (1.2MB)
├── assets/
│   ├── video1.mp4      ← hero background video (8MB)
│   └── video2.mp4      ← cocktail section video (34MB)
├── vercel.json         ← Vercel deploy config
└── README.md
```

> ⚠️ **Important:** Keep `index.html` and the `assets/` folder together.  
> The videos must be in `assets/` relative to `index.html`.

## Deploy to GitHub Pages

1. Push all files to GitHub (keep folder structure)
2. Settings → Pages → Source: `main` branch `/root`
3. Live at `https://yourusername.github.io/cafe-souvenir/`

## Deploy to Vercel (recommended — faster)

1. Import repo at [vercel.com](https://vercel.com)
2. No config needed — deploy as static
3. Live in ~30 seconds
